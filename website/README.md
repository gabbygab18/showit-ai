# Showit AI: Website

Download site for the Showit AI desktop app (Next.js + Tailwind v4), styled like the Pulse site.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build && npm start
```

Deploy on Vercel with **Root Directory = `website`**.

## Downloads

The buttons point at the latest GitHub release of `gabbygab18/showit-ai`, so each release needs these exact file names:

| File | From |
|---|---|
| `Showit-AI-win-x64-setup.exe` | `npm run dist` in the app (`release/`) |
| `showit-ai-demo-small.mp4` | the demo video (`demo/`) |

Screenshots live in `public/shots/`.
